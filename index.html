Lovely Bites quote tool

Prices come from menu-prices.csv. Jersey figures come from public-data.json. Nothing is typed in by hand.

1. Load the prices

The prices live in menu-prices.csv and the Jersey figures in public-data.json. A page opened by double-click isn't allowed to read other files by itself, so it has to be shown the lovelybites folder once.

After the first time this browser remembers the folder, so the prices load by themselves. If you edit the CSV while this page is open, it re-reads it when you come back to the page.
